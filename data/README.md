# Data

This folder contains the synthetic 24-hour ICU dataset used throughout the project.

- `synthetic_icu_24h.csv` — generated by `src/generate_synthetic_icu_data.py`.
  27,809 synthetic patients, 12 structured clinical variables, 10 LDA-style
  topic probability features, and 5 binary mortality outcome columns.

**This is not real patient data.** No MIMIC-III data or any other real
clinical records were used to create this file. If the CSV is missing,
regenerate it from the project root with:

```bash
python src/generate_synthetic_icu_data.py
```
